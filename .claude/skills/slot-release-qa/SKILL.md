# Slot Release & QA — Reference

How the two games build, package, and get verified before delivery. **Verify the
built artifact, not the source** (Schreier) — the harness below is how.

---

## 1. Build & package pipelines

**Pixi (`shining-pop`)** — single-file casino output:

- `npm run build` → Vite (`vite-plugin-singlefile`) → `dist/index.html` (JS
  inlined). This is the **committed playable review build** — keep it in sync.
- `npm run build:stake` → build + `scripts/inline-assets.mjs` (inline fonts/
  images/audio into one HTML for the RGS/Stake sandbox).
- `npm run package:stake` → `scripts/package-stake.mjs` (zip the deliverable).
- Asset generators: `scripts/gen-*.mjs` (ElevenLabs audio/music, crownwild
  fx/rig, reskin). Regenerate art/audio there, not by hand-editing assets.

**Cocos (`shining-pop-v2`)** — `build/web-mobile`, generated by the **Cocos
Creator editor** (Build panel) using `build-templates/web-mobile`
(`index.ejs` + `loader` + `style.css`). **There is no headless build** — source
edits are invisible in the committed `build/web-mobile` until rebuilt in the
editor. This is the #1 release gotcha; always state it.

**Shared:** `@artest/math-core` builds via `tsc`; `pnpm -r build` builds all.

## 2. The verification harness (Playwright — the unlock)

Renders the _built_ game headless so changes are seen, not guessed:

```js
import pw from '/opt/node22/lib/node_modules/playwright/index.js';
const { chromium } = pw;
chromium.launch({
  args: ['--use-gl=swiftshader', '--ignore-gpu-blocklist', '--enable-webgl', '--no-sandbox'],
});
// PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers ; serve the build dir over http
```

- Serve `games/shining-pop/dist` or `games/shining-pop-v2/build/web-mobile`.
- **Keyboard-drive** (letterbox-proof): Space=spin, B=buy. Pixi splash: click
  "TAP TO START" low-centre; Cocos load: wait ~10s headless.
- Burst-screenshot ~160–220ms after a spin to catch a win; Read to inspect,
  SendUserFile to share. **Pixi rebuilds here; Cocos does not** — screenshot the
  current Cocos build only.

---

## 3. CI gate (`.github/workflows/ci.yml`)

Every push/PR runs **lint · format:check · build + unit tests (both engines +
math-core) · RTP sim**. Guards in `games/shining-pop-v2/tests/` +
`packages/math-core/test/`: layering, MVC-direction, feel-contract, design-token
drift, feature/affordability, **RTP regression**. Keep all green.

**Open CI upgrades** (ROADMAP): asset-budget gate (Pixi single-file ~1.4 MB —
fail on >N% growth), visual-regression screenshot diffing, typecheck the Cocos
view layer with a stubbed `cc`.

---

## 4. Device / orientation / a11y matrix

Test each before delivery:

- **Orientation:** portrait (mobile-first) + landscape; the relayout must not
  clip (logo vs reels, spin button vs viewport edge).
- **Presets:** the 7 Stake viewport sizes (Popout S … 1920×1080); tiny floors.
- **Reduced-motion:** every VFX has a calm fallback (gated in code) — verify it.
- **Sound-off / muted:** remembered; visuals still read.
- **Low-end GPU:** `_gpuWeak` path (Pixi) trims overdraw; confirm no jank.
- **Safe-area:** notch/home-indicator insets on edge controls.

---

## 5. Pre-release checklist

- [ ] `pnpm -r build` clean; `pnpm test` + `pnpm sim` green.
- [ ] Pixi `dist` rebuilt & committed; Cocos `build/web-mobile` rebuilt in editor.
- [ ] Playwright pass: base / win / big-win / buy-modal captured both orientations.
- [ ] Asset budget within limit (no surprise bundle growth).
- [ ] Compliance checklist (see `slot-compliance-rgs`) signed off.
- [ ] RTP/max-win disclosure matches the certified math.
- [ ] No console errors on load (both engines).
- [ ] Reduced-motion + sound-off verified.
- [ ] `package:stake` zip opens and runs in the sandbox.
- [ ] CHANGELOG + PARITY-MATRIX updated.

---

## 6. Gotchas (release-specific)

- **Cocos build is stale until editor-rebuilt** — the single biggest "it didn't
  change" trap.
- **Committed review builds** (`dist`, `build/web-mobile`) are intentional (see
  `.gitignore` note) — keep Pixi's in sync; flag Cocos's as needing a rebuild.
- **`packages/*/dist`** are generated (gitignored) — don't commit them.
- **Letterbox** (Pixi 1200×675) breaks pixel-coordinate automation — use keyboard.
- **Commit rules:** conventional type + lowercase subject (commitlint); husky
  runs lint+prettier on commit.

> Method: build → serve → Playwright-verify (Pixi) / editor-verify (Cocos) →
> green CI → package. Pairs with the other four skills.
