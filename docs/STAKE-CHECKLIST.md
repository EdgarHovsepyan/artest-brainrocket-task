# Casino-RGS approval checklist

Internal engineering reference for shipping a game to the Stake Engine platform.
(Internal doc — shipped artifacts must contain **no** platform/Stake/Pascal names.)

## Math

- RTP within **90–98%**; all modes within **0.5pp** of each other.
- Verify the lookup-table RTP equals the target (artifact-weighted, not a formula).
- Advertised max win must be **empirically obtainable** (≥ ~1 in 10–20M) — advertise
  the empirical figure, not the theoretical wincap.
- Non-zero-win hit rate ≥ ~5%.
- Outcome books validated: unique ids, full lookup↔book coverage, positive weights.
- Three-way RTP cross-check: theoretical vs simulated vs artifact-weighted.
- Sign-off at ≥20M spins, reproducible seed; tolerance ≤0.20% absolute.

## Frontend (single file)

- One self-contained `index.html` — JS, CSS, **all assets base64-inlined**, **zero
  external resources** (hard build gate).
- No scrolling at all 7 presets (Desktop 1200×675 … Popout S 400×225, Mobile S 320×568).
- Console **silent** in prod (gate logs behind `?debug=true`); no 4xx/5xx under slow-3G autoplay.
- Money never recomputed on the client: read `payoutMultiplier` from events; **`Math.round`, never `Math.floor`**.
- Crypto-safe currency (test `?currency=BTC`), no hardcoded `$`; spacebar → spin; autoplay confirmation; sound toggle.

## Stateless + replay

- No jackpots/cashout/localStorage round-state; mid-round refresh resumes via `auth.round.active`.
- **Bet Replay mandatory**: `?replay=true`, public `GET /bet/replay/...` (no auth), all controls disabled, disclaimer + disclosure fields, `0.00x` on loss.

## Money/RGS wire

- Money integer ×10⁶; payout multipliers ×100. `rgs_url` arrives without scheme — normalize.
- `end-round` fires **after** the win celebration completes.

## Submission (ACP)

- Two **independent** uploads: Math (index.json + lookup CSV + books) and Front End (the single file).
- After Publish, the **Versions picker must select the new math + front** — skipping silently keeps the old version active (the #1 rejection).

## ARTEST brand gate

- `brand-lint` must find **no** `stake` / `pascal` / `betconstruct` tokens in shipped `dist/**` (front HTML + math JSON/CSV); only ARTEST | BrainRocket branding ships.
